# Package index

## Economic benefit

Estimate the annual dollar value of dung beetle activity to a cattle
operation.

- [`calc_dung_beetle_benefit()`](https://StanbrookBuyer.github.io/RancheR/reference/calc_dung_beetle_benefit.md)
  : Estimate the annual economic benefit of dung beetles to a ranch
- [`scenario_decay_rate()`](https://StanbrookBuyer.github.io/RancheR/reference/scenario_decay_rate.md)
  : Decay rate (g/day) for a scenario
- [`dung_scenarios()`](https://StanbrookBuyer.github.io/RancheR/reference/dung_scenarios.md)
  : The three dung beetle abundance scenarios

## Climate-based decay

Adjust the reference decay rates for a location’s climate, using
WorldClim warmest-quarter bioclim variables.

- [`estimate_local_decay()`](https://StanbrookBuyer.github.io/RancheR/reference/estimate_local_decay.md)
  : Estimate local dung decay rates from a location's climate
- [`bioclim_warmest_quarter()`](https://StanbrookBuyer.github.io/RancheR/reference/bioclim_warmest_quarter.md)
  : Look up warmest-quarter bioclim variables for a location
- [`climate_decay_factor()`](https://StanbrookBuyer.github.io/RancheR/reference/climate_decay_factor.md)
  : Climate scaling factor for dung decay

## Reference data

Paper-derived constants and calibration values.

- [`rancher_constants`](https://StanbrookBuyer.github.io/RancheR/reference/rancher_constants.md)
  : Paper-derived constants for the dung beetle valuation model
